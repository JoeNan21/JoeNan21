# Mode: sorrento

Venue / events commercial mode.

## Focus

Revenue, bookings, event economics, conversion, utilisation, high-value
opportunities, referrals, decision-makers and influencers, site visits,
competitive positioning, booking multiplication potential.

## Signal weighting

| Signal | Weight |
|---|---|
| `conversion_evidence` | 1.5 |
| `unit_economics` | 1.4 |
| `utilisation` | 1.3 |
| `referral_potential` | 1.3 |
| `economic_buyer` | 1.2 |
| `competition` | 1.1 |

| `activity` | 0.4 (deliberately suppressed) |

## Mode-specific reasoning

- **Date scarcity is a real constraint.** A booking consumes a finite date.
  Accepting a low-value booking on a high-demand date has an opportunity cost
  that must be scored, not ignored.
- **Booking multiplication.** An event whose attendees are themselves buyers
  (corporate functions, industry events) carries referral value beyond its own
  revenue. This must be evidenced, not assumed.
- **Site visits convert.** Where conversion evidence exists, actions that produce
  a site visit rank highly. Where it does not exist for this segment, that is an
  unknown, not a given.

## Traps

- Headline booking value without cost-to-serve.
- Utilisation optimised at the expense of yield.
- "Exposure" or "profile" events with no conversion path — `prestige_as_value`.
